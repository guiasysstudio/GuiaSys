Site público da GuiaSys Studio.

- Domínio: https://www.guiasys.online/

- Identidade: #019A98 e #18212D

- `/projetos/guiaplay/` — GuiaPlay
- `/sobre/` — Sobre
- `/contato/` — Contato
- `/login/` — Login
- `/cadastro/` — Cadastro
- `/conta/` — Área autenticada
- `/conta/perfil/` — Perfil completo do cliente
