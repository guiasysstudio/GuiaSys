Sobre a GuiaSys

Se a dúvida for específica de um projeto, a própria página do projeto pode ter respostas adicionais.

Ainda tenho uma dúvida
O que a GuiaSys Studio desenvolve?

Programas para computador, sites, aplicações web e soluções que podem integrar mais de uma plataforma quando isso fizer sentido para o projeto.

Todos os projetos aparecem na página Projetos?

Não. Somente projetos que foram marcados como públicos aparecem no portal. Projetos ainda em preparação permanecem ocultos.

Posso solicitar um projeto personalizado?

Sim. A página Solicitar projeto permite explicar a necessidade, o tipo de solução imaginado e os detalhes iniciais.

Os downloads ficam disponíveis mesmo quando não existem arquivos oficiais?

Não. A GuiaSys não exibe botões de download fictícios. Um download só aparece quando houver um destino funcional e oficial.

Preciso de conta para conhecer os projetos?

Não. A navegação pública pode ser feita sem conta. Recursos de cliente que dependem de identificação usam a conta GuiaSys.

Como entro em contato?

Você pode usar o formulário do site ou o WhatsApp oficial informado na página Contato.

A GuiaSys trabalha com aplicativos móveis?

A linha móvel só será apresentada publicamente como oferta quando houver uma estrutura completa para Android e iOS.
